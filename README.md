# Armond Guze Portfolio

Resume-ready software developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Three.js.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Contact Email

The contact form uses `VITE_APP_CONTACT_EMAIL` when it is available. Without that value, the form still prepares and copies the message so the visitor can send it using the contact details on the resume.
